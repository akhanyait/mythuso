# Integration notes — accessibility and language

Every shared file this branch touched, and what it added to each. Written for whoever merges this
beside other work on the same tree.

## New files

| File | What it is |
|---|---|
| `packages/catalog/locales.json` | The locale contract. Eleven written languages, 85 keys in three sets (`shell`, `hero`, `console`), the review state of each language, the clinical language rule, and the South African Sign Language accommodation. Nothing else may hold a translated string. |
| `scripts/emit-locales.mjs` | Generates `LocalisationData.swift` and `LocalisationData.kt` from that contract. Follows `emit-vetting.mjs`. Converts the contract's `|` line break into `\n` for native, which is the one rename it makes. |
| `apps/ios/MyThuso/Models/LocalisationData.swift` | Generated. `ThusoLocale`, `ThusoString`, the table, `thuso()`, `clinicalLocale()`, `ThusoLanguageNotes`. |
| `apps/android/.../model/LocalisationData.kt` | Generated. The Kotlin equivalent. |
| `apps/web/src/features/Access.tsx` | The *Language & access* screen: the language table with review state, the clinical language rule, and the SASL accommodation. Renders from the contract; holds no copy of its own. |
| `tests/accessibility.spec.ts` | 320 px and 200 %-zoom journeys on both project viewports. Measures horizontal overflow, target size and rendered text size. |
| `docs/ACCESSIBILITY.md` | What is tested, what was read by hand, and what is not done at all. |

## Shared files changed

**`scripts/check-boundaries.mjs`** — the largest merge surface.
- The old locale check (each of three files mentions each of four locale codes, lines 57–65) is
  **deleted** and replaced by a block of locale checks reading `packages/catalog/locales.json`.
- The old hero-copy check (six call-to-action substrings across three files) is **deleted** and
  replaced by a check that each slide has all seven of its parts in the contract's `hero` set, and
  that the number of slides matches the number of cut-outs.
- Added: a colour-contrast section (WCAG 2.2 relative luminance, computed from the token file), the
  focus-ring token check, `emitLocales()` in the `generated` list, and the language-picker checks.
- The final `console.log` summary gained two sentences.
- If you are merging another branch that also edits this file, the conflicts will be in the locale
  block near the top and in the `generated` array.

**`package.json`** — added the `locales` script; `generate` now ends with `&& npm run locales`.

**`packages/design-tokens/tokens.json`** — added three top-level sections and two typography keys:
- `typography.minimumRendered` (11) and `typography.minimumRenderedNote`.
- `targets` — the 44 px floor, the 24 px absolute floor, and three declared exemptions with reasons.
  `tests/accessibility.spec.ts` reads this.
- `contrast` — 26 measured pairs, 6 known failures each with a measured proposed fix, and 2 tokens
  explicitly not measured with the reason. `scripts/check-boundaries.mjs` reads this.
- **No colour value was changed.** The six failures are recorded, not fixed.

**`apps/web/src/lib/i18n.ts`** — rewritten. It now reads `packages/catalog/locales.json` rather than
holding the dictionaries. `locales`, `useT`, `LocaleContext` and `LocaleCode` keep their names and
shapes; `LocaleCode` is now `string` rather than a literal union. New exports: `t`, `clinicalLocale`,
`useClinicalLocale`, `missingSets`, `sets`, `clinicalRule`, `signLanguage`, `fallbackRule`,
`translationHonesty`. `t()` falls back to English and then to the readable half of the key.

**`apps/web/src/App.tsx`** — the `Language` dialog rewritten (review state per option, the unreviewed
notice, which sets a language does not cover, and SASL as a checkbox rather than a radio); a
`Language & access` sidebar link and route; two new imports.

**`apps/web/src/features/Pages.tsx`** — one row added to `menuGroups`, and the `Languages` icon
imported.

**`apps/web/src/styles.css`** — two appended sections at the end: the language table and access-rule
styles, and the accessibility sizing section. One change inside the existing file: eight
`outline:3px solid var(--gold)` became `var(--amber)` — the focus ring measured 2.12:1 and failed
WCAG 2.2 SC 1.4.11. `gold` stays in the palette and is still used elsewhere.

**`apps/ios/MyThuso/Models/Localisation.swift`** — reduced to `validateSaId`, `HeroSlideCopy` and
`heroSlides()`. The enum, the table and `thuso()` moved into the generated file. `heroSlides()` now
reads the table instead of switching on the locale.

**`apps/android/.../model/Localisation.kt`** — the same reduction.

**`apps/ios/MyThuso.xcodeproj/project.pbxproj`** — regenerated by `scripts/generate-xcode-project.py`
to pick up `LocalisationData.swift`. Regenerate rather than merge if this conflicts.

**iOS view files** — `GuardianView.swift` (the language screen: review state, the clinical rule and
the SASL accommodation), `OnboardingView.swift` (review state in the first-run picker),
`PassportView.swift` and `HouseholdView.swift` (`.household` renamed to `.householdRecord`, because

**`apps/android/app/build.gradle.kts`** — a `lint { }` block: `abortOnError`, and four accessibility

**`tests/deep-journeys.spec.ts`** — two selectors: `/^Language/` became `/^Language Read MyThuso/`,

**`docs/FEATURE-MAP.md`** — the `Localisation` row in "Delivered as interactive design" replaced by

**`CLAUDE.md`** — one line: `npm run generate` now lists locales.

## Two behaviour changes worth flagging in review

`LocaleCode` is `string`, not a union of four literals. Anything that switched exhaustively on a
locale code will now compile without a default branch. Nothing in the tree did.

The four original languages are labelled **machine-drafted**, not reviewed. No review was ever
recorded for isiZulu, Sesotho or Afrikaans, so none is claimed. Changing that needs a name, an
organisation and a date in the contract; the build refuses the claim without them.
