# How-it-works portraits

Original illustrative portraits generated with the built-in image-generation tool in new-image mode. These represent a patient, nurse and doctor; they do not identify actual MyThuso staff or patients. Animated orbit lines are native CSS behind each circular portrait, governed by the page's Pause motion control and reduced-motion preferences.

The doctor step and section heading now explain that a registered doctor may decide to visit the patient at home. This is a presentation change to the care journey.

Project assets are 512px JPEG derivatives, sized and encoded for web delivery with sips (quality 85); composition is unchanged. Original full-resolution outputs remain in `/Users/gilbertmakinana/.codex/generated_images/01a09a40-cba4-75e2-b4aa-0856fe1ffec7/`.
